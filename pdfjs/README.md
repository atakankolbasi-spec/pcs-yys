# pdf.js (pdfjs-dist 3.11.174)

Mozilla pdf.js, Apache-2.0 lisansı (`LICENSE.txt`). NCTS Transit Refakat Belgesi (PDF) yazı katmanı tarayıcıda okunur
(`app.js`: `pdfText`); belge dışarı gönderilmez, kota yoktur. Dosyalar npm paketinden olduğu gibi alınmıştır
(`build/pdf.min.js`, `build/pdf.worker.min.js`); güncellemek için `npm pack pdfjs-dist@<sürüm>` ile aynı iki dosya değiştirilir.
